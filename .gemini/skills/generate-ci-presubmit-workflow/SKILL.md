# Generate CI Presubmit Workflow

This skill guides an automated agent through adding per-service E2E test presubmits and regenerating `.github/workflows/ci-presubmit.yaml`.

## Overview

Config Connector presubmits run in GitHub Actions. The main workflow `.github/workflows/ci-presubmit.yaml` is generated by `dev/tasks/generate-github-actions`, which scans `dev/ci/presubmits/` and creates a 1:1 job for each executable script.

## Step-by-Step Instructions

### 1. Create a Per-Service Presubmit Script

Create `dev/ci/presubmits/tests-e2e-samples-<service_name>` (e.g., `tests-e2e-samples-storage`) and make it executable (`chmod +x`).

Template:
```bash
#!/bin/bash
# Copyright 2026 Google LLC
#
# Licensed under the Apache License, Version 2.0 (the "License");
# you may not use this file except in compliance with the License.
# You may obtain a copy of the License at
#
#      http://www.apache.org/licenses/LICENSE-2.0

# distributed under the License is distributed on an "AS IS" BASIS,
# WITHOUT WARRANTIES OR CONDITIONS OF ANY KIND, either express or implied.
# See the License for the specific language governing permissions and
# limitations under the License.

set -o errexit
set -o nounset
set -o pipefail

REPO_ROOT="$(git rev-parse --show-toplevel)"
cd ${REPO_ROOT}/

. ${REPO_ROOT}/dev/tasks/setup-envtest

echo "Running fixtures in tests/e2e for <service_name>..."

MOCK_GROUP_EMAIL="test@group.com"

RUN_E2E=1 \
E2E_KUBE_TARGET=envtest \
E2E_GCP_TARGET=mock \
KCC_USE_DIRECT_RECONCILERS="ComputeForwardingRule,SpannerInstance" \
KCC_ENG_GROUP_EMAIL="${MOCK_GROUP_EMAIL}" \
RUN_TEST_APIGROUP="<service_name>.cnrm.cloud.google.com" \
  go test -test.count=1 -timeout 1h30m -v ./tests/e2e -run TestAllInSeries/samples
```

### 2. Exclude Service from Unclassified Tests

Open `dev/ci/presubmits/tests-e2e-samples-unclassified` and add `<service_name>.cnrm.cloud.google.com` to the comma-separated `SKIP_TEST_APIGROUP` variable to avoid duplicate test runs.

### 3. Regenerate the GitHub Actions Workflow

Run the generator script from the repository root:
```bash
./dev/tasks/generate-github-actions
```

### 4. Verify

Check `git diff .github/workflows/ci-presubmit.yaml` to confirm the new job has been generated.

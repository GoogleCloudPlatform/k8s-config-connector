# ComputeProjectMetadata Identity and Reference Journal

## Observations & Learnings

- **Singleton / Project-Level Compute Resource Identity:** ComputeProjectMetadata represents the project-wide metadata in Compute Engine (`compute.googleapis.com/Project`), configured via the `setCommonInstanceMetadata` Compute Engine API method on `projects/{project}`. Therefore, its GCP resource identity URL is `projects/{project}` with host `compute.googleapis.com`.
- **CAIS Template Matching:** In `cloudassetinventory_names.jsonl`, `compute.googleapis.com/Project` defines the format `//compute.googleapis.com/projects/{{PROJECT_ID}}`. The `gcpurls.Template` for `ComputeProjectMetadataIdentity` (`compute.googleapis.com` with `projects/{project}`) normalizes to `//compute.googleapis.com/projects/{}`, which already matches the CAIS entry without requiring an exception in `pkg/gcpurls/registry_test.go`.
- **Spec-Only Identity Resolution Without Schema Change:** `ComputeProjectMetadataSpec` contains only `metadata: map[string]string` and does not define a `projectRef` or `resourceID`. The project is resolved via standard KCC annotations (such as `cnrm.cloud.google.com/project-id`) or the resource's namespace using `refs.ResolveProjectID`. Additionally, `ComputeProjectMetadataStatus` only contains `conditions` and `observedGeneration` (no `externalRef` or `selfLink`). Per skill instructions, no schema changes were made, and `GetIdentity` extracts the identity directly from the resolved project.
- **Legacy Normalization with Fallback:** Because `ComputeProjectMetadata` is a legacy resource lacking `status.externalRef`, `ComputeProjectMetadataRef.Normalize` leverages `refs.NormalizeWithFallback`. In accordance with the skill rules, the fallback inspects `status.conditions` using `isResourceReady(u)` before deriving the identity from spec, ensuring non-ready resources bubble up a `k8s.NewReferenceNotReadyError`.
- **Golden Identity Verification:** Running `TestGoldenIdentitiesYamlFiles` updated `pkg/test/resourcefixture/testdata/basic/compute/v1beta1/computeprojectmetadata/_identities.yaml`, changing the previously unresolved `caisURL: unknown` to `//compute.googleapis.com/projects/${TEST_DEPENDENT_ORG_PROJECT_ID}`.

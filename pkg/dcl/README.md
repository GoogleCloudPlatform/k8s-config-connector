# DCL Controller and Schema Integration

This package implements the Declarative Resource Client Library (DCL) dynamic controller and schema mapping for Config Connector.

Approximately 20% of legacy Config Connector resources are backed by DCL.

For instructions on upgrading the DCL dependency, regenerating schemas, verifying CRD diffs, and testing DCL resources, please refer to the [DCL Field and Resource Additions Playbook](../../docs/develop-resources/scenarios/dcl-field-and-resource.md).

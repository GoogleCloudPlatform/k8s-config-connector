Global APIs (like `apikeys.googleapis.com`) strictly require `X-Goog-User-Project` when authenticating with OAuth client credentials.

## 4. Environment and Factory Problems to File

1. **Duplicate Task Dispatch Race Condition**:
   * **Issue**: The factory dispatched concurrent duplicate tasks for the same resource step (Issue #14593 vs #14571 for `SaaSServiceMgmtRollout`, and Issue #14692 vs #14628 for `DataplexDataScan`).
   * **Impact**: Substantial wasted agent inference compute. PRs #14615 and #14693 had to be closed unmerged once their sibling PRs merged.
   * **Action for factory team**: Add deduplication guards in the task dispatcher so that only one active task or PR exists per resource and step at any given time.

2. **Human Edits Metric Rollup Distortion**:
   * **Issue**: In `outcomes.jsonl`, all 21 PRs with recorded "human edits" showed `added: 0, deleted: N` (e.g. PR #14640: +0 -948; PR #14504: +0 -5236).
   * **Impact**: Maintainer actions such as squashing commits on GitHub, rebasing against master, or pushing a squashed branch cause git diff to register the old unsquashed agent head commits as "deleted by human".
   * **Action for factory team**: Refine the human edit detection algorithm to compare the squashed merge commit against the agent's work tree content (tree hash / semantic diff) rather than raw commit parentage.

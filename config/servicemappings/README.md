# Service Mappings

This directory contains `ServiceMapping` configuration files that define how Config Connector's dynamic/Terraform-based controller maps between Kubernetes Custom Resource Definitions (CRDs) and Terraform Provider Google Beta resources.

For detailed instructions on modifying service mappings, whitelisting fields, declaring resource references, and generating CRDs, see the [Terraform Field and Resource Playbook](../../docs/develop-resources/scenarios/terraform-field-and-resource.md).

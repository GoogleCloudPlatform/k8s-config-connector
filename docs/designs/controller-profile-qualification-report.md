## 2. Shadow-Mode Evaluation: Repository-Wide Analysis

To prove that the Controller Profile trait model accurately models Config Connector's direct controllers, an AST-based shadow evaluation suite was constructed in `dev/tools/controllerbuilder/pkg/controllerprofile/shadow/`.

### 2.1 Methodology
The shadow evaluator uses Go's `go/parser` and `go/ast` to inspect both the existing controller source files in `pkg/controller/direct/` and the synthetic controllers generated by `ControllerProfile`.

The analyzer inspects structural compliance across 8 core contracts:
1. **`Model Registration`**: Invocation of `registry.RegisterModel(GVK, New<Kind>Model)`.
2. **`Model Factory`**: Constructor function satisfying `directbase.Model`.
3. **`Client Initialization`**: Construction of REST or gRPC clients with credentials and endpoints.
4. **`AdapterForObject`**: Unstructured conversion, identity extraction, reference normalization, and mapper invocation.
5. **`AdapterForURL`**: External URL parsing and adapter construction.
6. **`Find`**: Retrieval of actual state and `404 Not Found` handling.
7. **`Create / Update / Delete`**: Request preparation, RPC dispatch, LRO polling, and status reconciliation.
8. **`Export`**: Reconstruction of KRM spec, identity fields (`projectRef`, `location`, `resourceID`), metadata labels, and GVK.

## 4. Key Engineering Bugs Caught & Resolved During Qualification

During the qualification loop, several non-obvious failure modes were identified and fixed in the code generation template:

### 1. Unstructured Conversion Order Bug in `Export()`
- **Issue**: Previously, `u.Object = uObj` was invoked after `u.SetName(...)` and `u.SetGroupVersionKind(...)`.
- **Root Cause**: `uObj` produced by `runtime.DefaultUnstructuredConverter.ToUnstructured` only contains fields from the typed struct. Assigning `u.Object = uObj` overwrote the root map, wiping out `apiVersion` and `kind`. This caused controller-runtime to fail with `error getting resource config for ""`.
- **Fix**: Re-ordered the template so `u.Object = uObj` is assigned first, followed by `u.SetName(...)`, `u.SetGroupVersionKind(...)`, and label export.

### 2. Diffing with Read-Only GCP Fields
- **Issue**: Standard proto equality checks flagged server-assigned timestamps (`createTime`, `updateTime`) as user drift during re-reconciliation.
- **Root Cause**: Desired proto lacks status fields, but actual proto contains them.
- **Fix**: Integrated `mappers.OnlySpecFields(actual, Spec_FromProto, Spec_ToProto)` to project actual GCP state onto the KRM spec schema before passing to `common.DiffForTopLevelFields`.

### 3. Protobuf `Empty` LRO Response Handling on Delete
- **Issue**: GCP LRO delete operations return `google.protobuf.Empty` inside `response.value`. In some environments, deserialization produced `missing "value" field` errors.
- **Fix**: Added safe error suppression for empty values in delete LRO completion:
  ```go
  if err != nil && !direct.IsNotFound(err) && !strings.Contains(err.Error(), "missing \"value\" field") {
      return false, fmt.Errorf("waiting delete %s: %w", a.id, err)
  }
  ```
